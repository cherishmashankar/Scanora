# Scanora

Scanora is a modern Android QR code and barcode scanner built with Kotlin and Jetpack Compose.

## Features

- Scan QR codes and barcodes
- QR and barcode result previews
- Save scan results
- View and search scan history
- Share scanned content
- Open scanned URLs
- Delete saved scans
- Camera flash support
- English and German support

## Built With

- Kotlin
- Jetpack Compose
- Material 3
- CameraX
- ML Kit
- Room
- Hilt
- Coroutines & Flow
- ZXing

## Status

Scanora is currently under active development.

The first release is being prepared for the Google Play Store.
