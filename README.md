
# Scanora

Scanora is a modern Android QR code and barcode scanner built with Kotlin and Jetpack Compose.

## Features

- Scan QR codes and barcodes using the camera
- Import images from the gallery to scan QR codes and barcodes (V2)
- QR and barcode result previews
- Save scan results
- View and search scan history
- Share scanned content
- Open scanned URLs
- Delete saved scans
- Camera flash support
- Loading indicators and error handling for gallery scanning
- English and German support

## Built With

- Kotlin
- Jetpack Compose
- Material 3
- CameraX
- ML Kit
- Room
- Hilt
- Coroutines & Flow
- ZXing
- JUnit & Mockito
